# 🔍 Как посмотреть списания по договору

## ✅ Рекомендуемый способ: Отладочный эндпоинт

Создан специальный эндпоинт для полного анализа договора:

### URL:
```
GET /api/auth/billing/contracts/by-number/{НОМЕР_ДОГОВОРА}/analysis
```

### Пример для договора "Т-041225/065":

**Вариант 1: Через браузер (с URL-кодированием)**
```
http://localhost:8080/api/auth/billing/contracts/by-number/Т-041225%2F065/analysis
```
(Символ `/` кодируется как `%2F`)

**Вариант 2: Через curl**
```bash
TOKEN="ваш_токен"
curl -H "Authorization: Token $TOKEN" \
  "http://localhost:8080/api/auth/billing/contracts/by-number/Т-041225%2F065/analysis" | jq
```

**Вариант 3: Через Postman/Insomnia**
- Метод: `GET`
- URL: `http://localhost:8080/api/auth/billing/contracts/by-number/Т-041225%2F065/analysis`
- Headers: `Authorization: Token ваш_токен`

## 📋 Альтернативные способы

### Способ 2: Через список счетов с фильтром

```
GET /api/auth/billing/invoices?contract_id={ID_ДОГОВОРА}
```

**Минус:** Нужен ID договора (не номер). Сначала найдите ID через:
```
GET /api/auth/contracts
```

### Способ 3: Через веб-интерфейс

1. Откройте раздел **"Биллинг и договоры"** → вкладка **"Счета"**
2. Используйте фильтры для поиска по договору
3. Откройте конкретный счёт для просмотра деталей

---

## 💡 Как получить токен авторизации?

Токен можно найти:
1. В консоли браузера (F12 → Application → Local Storage)
2. В заголовках запросов (Network tab → любой запрос → Headers)
3. Через API логина (если есть доступ)

---

## 🚀 Быстрый старт

1. **Убедитесь, что бэкенд-сервер запущен и перезапущен** (чтобы новый эндпоинт заработал)
2. **Найдите токен авторизации** (см. выше)
3. **Выполните запрос** одним из способов выше

---

## 📝 Примечания

- Номер договора в URL должен быть URL-encoded (`/` → `%2F`)
- Для партнерских договоров списания рассчитываются на основе ежедневных снимков объектов
- Все суммы в рублях (RUB)
