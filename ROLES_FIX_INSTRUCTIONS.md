# 🔧 Инструкция по исправлению отображения ролей

## 🎯 Проблема
В интерфейсе пользователей в колонке "Роль" отображается "Не назначена" для всех пользователей из Axenta.

## ✅ Решение реализовано

### Что исправлено:
1. **Автоматическое назначение ролей** на основе `accountType` из Axenta API
2. **Создание ролей по умолчанию** в tenant схемах при первом запросе
3. **Обновленный API ответ** с полной информацией о ролях

## 🚀 Как применить исправление:

### Шаг 1: Перезапустите сервер
```bash
cd /Users/com/backend_axenta
go run main.go
```

### Шаг 2: Обновите страницу пользователей в браузере
- Перейдите на страницу "Пользователи"
- Обновите страницу (F5 или Ctrl+R)
- Роли должны автоматически назначиться при первом запросе

### Шаг 3: Проверьте результат
После обновления страницы в логах сервера должны появиться сообщения:
```
⚠️ Role partner not found in tenant schema, creating default roles...
✅ Created default role: partner
✅ Created default role: client  
✅ Created default role: user
✅ Role partner created and found (ID: 1)
```

## 🔍 Диагностика (если роли все еще не отображаются)

### Тест 1: Проверьте создание ролей
```bash
curl -H "Authorization: Token YOUR_TOKEN" \
     http://localhost:8080/api/auth/test/roles
```

### Тест 2: Проверьте пользователя с ролью
```bash
curl -H "Authorization: Token YOUR_TOKEN" \
     http://localhost:8080/api/auth/test/user-role
```

### Тест 3: Проверьте основной API пользователей
```bash
curl -H "Authorization: Token YOUR_TOKEN" \
     http://localhost:8080/api/auth/users
```

## 📋 Ожидаемый результат

### В API ответе должно быть:
```json
{
  "status": "success",
  "data": {
    "items": [
      {
        "id": 123,
        "username": "partner_user",
        "account_type": "partner",
        "role_id": 1,
        "role": {
          "id": 1,
          "name": "partner",
          "display_name": "Партнер",
          "color": "#2196F3"
        },
        "axenta_user_type": "partner",
        "is_axenta_user": true
      }
    ]
  }
}
```

### В интерфейсе должно отображаться:
- Вместо "Не назначена" → **"Партнер"** (для partner)
- Вместо "Не назначена" → **"Клиент"** (для client)
- С соответствующими цветами: синий для партнеров, зеленый для клиентов

## 🆘 Если проблема не решилась

1. **Проверьте логи сервера** на наличие ошибок
2. **Убедитесь, что используется правильный токен** Axenta
3. **Проверьте, что база данных доступна** и схемы созданы
4. **Очистите кэш браузера** и обновите страницу
5. **Проверьте Network tab** в DevTools на наличие ошибок API
