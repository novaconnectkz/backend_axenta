# 📦 РУКОВОДСТВО: Загрузка ВСЕХ объектов из Axenta Cloud

## ✅ ЧТО БЫЛО РЕАЛИЗОВАНО

Планировщик снимков теперь загружает **ВСЕ объекты и аккаунты** из Axenta Cloud **независимо от наличия договоров**.

### Новая логика работы:

```
┌─────────────────────────────────────────────────────────┐
│  1. Проверяем наличие системного токена                │
│     AXENTA_ADMIN_TOKEN                                  │
│                                                          │
│  2. Если токен есть:                                    │
│     ✅ Загружаем ВСЕ аккаунты из Axenta Cloud          │
│     ✅ Загружаем ВСЕ объекты                           │
│     ✅ Сохраняем в таблицы:                            │
│        - axenta_account_snapshots                       │
│        - axenta_object_snapshots                        │
│                                                          │
│  3. Если системного токена нет:                        │
│     ⚠️ Используем токены партнеров из БД              │
│     ⚠️ Загружаем только их аккаунты                   │
│                                                          │
│  4. В любом случае:                                    │
│     ✅ Создаем снимки для договоров                    │
│     ✅ Сохраняем в partner_daily_snapshots             │
└─────────────────────────────────────────────────────────┘
```

## 🔑 КАК ПОЛУЧИТЬ ТОКЕН AXENTA CLOUD

### Вариант 1: Через веб-интерфейс Axenta
1. Войдите на https://axenta.cloud
2. Перейдите в Настройки → API → Токены
3. Создайте новый токен с правами на чтение аккаунтов и объектов
4. Скопируйте токен

### Вариант 2: Через API
```bash
curl -X POST https://axenta.cloud/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{
    "username": "ваш_email@example.com",
    "password": "ваш_пароль"
  }'
```

Ответ содержит токен в поле `token`.
