# Система скидок для партнерских договоров

## Описание

Добавлена система скидок для партнерских договоров с двумя режимами работы:
1. **Ручная скидка** - устанавливается вручную администратором
2. **Автоматическая скидка** - рассчитывается на основе количества активных объектов

## Правила автоматических скидок

Скидки применяются автоматически на основе количества **активных** объектов партнера:

| Количество активных объектов | Скидка |
|------------------------------|--------|
| ≥ 4000                       | 30%    |
| ≥ 2000                       | 20%    |
| ≥ 1000                       | 10%    |
| < 1000                       | 0%     |

```go
CostBeforeDiscount decimal.Decimal // Стоимость до применения скидки
DiscountAmount     decimal.Decimal // Сумма скидки

```

## Формула расчета

### 1. Базовая стоимость
```
Дневная цена = Месячный тариф ÷ 30 дней (округляется до 4 знаков)
Стоимость до скидки = Дневная цена × Количество активных объектов
```

### 2. Применение скидки
```
Процент скидки = CalculateAutoDiscount(активных_объектов) ИЛИ ManualDiscountPercent
Сумма скидки = Стоимость до скидки × (Процент скидки ÷ 100)
Итоговая стоимость = Стоимость до скидки - Сумма скидки
```

### 3. Пример расчета

**Исходные данные:**
- Месячный тариф: 70 ₽/мес
- Активных объектов: 1152

**Расчет:**
1. Дневная цена = 70 ÷ 30 = 2.3333 ₽/день
2. Стоимость до скидки = 2.3333 × 1152 = 2687.96 ₽
3. Процент скидки = 10% (т.к. 1152 ≥ 1000)
4. Сумма скидки = 2687.96 × 0.10 = 268.80 ₽
5. **Итоговая стоимость = 2687.96 - 268.80 = 2419.16 ₽**

## Настройка скидок

### Вариант 1: Ручная скидка

Установите скидку вручную при создании/редактировании договора:

```json
{
  "discount_type": "manual",
  "manual_discount_percent": 15.5,
  "use_auto_discount": false
}
```

### Вариант 2: Автоматическая скидка

Включите автоматический расчет скидок:

```json
{
  "discount_type": "auto",
  "use_auto_discount": true
}
```

### Отключение скидок

```json
{
  "discount_type": "none",
  "manual_discount_percent": 0,
  "use_auto_discount": false
}
```

## API

### Создание договора со скидкой

```bash
POST /api/auth/contracts
{
  "contract_type": "partner",
  "partner_company_id": 2,
  "tariff_plan_id": 1,
  "discount_type": "auto",
  "use_auto_discount": true,
  ...
}
```

### Обновление скидки существующего договора

```bash
PUT /api/auth/contracts/:id
{
  "discount_type": "manual",
  "manual_discount_percent": 15,
  "use_auto_discount": false
}
```


**Колонка "Скидка":**
- Если есть скидка: зеленый чип с процентом + сумма скидки
- Если нет скидки: прочерк "—"

**Колонка "Стоимость за день":**
- Если есть скидка: 
  - Серая зачеркнутая стоимость до скидки
  - Зеленая итоговая стоимость со скидкой
- Если нет скидки: обычная стоимость

## Логика работы

### При создании снимка

1. Получается количество активных объектов из Axenta Cloud API
2. Определяется тип скидки из договора:
   - Если `discount_type = "manual"` → используется `manual_discount_percent`
   - Если `discount_type = "auto"` или `use_auto_discount = true` → вызывается `CalculateAutoDiscount(activeObjectsCount)`
   - Иначе → скидка = 0%
3. Рассчитывается стоимость:
   - Базовая стоимость
   - Сумма скидки
   - Итоговая стоимость
4. Все данные сохраняются в снимок для истории

### Автоматический пересчет

При изменении количества объектов:
- Автоматические скидки пересчитываются при каждом новом снимке
- Ручные скидки остаются неизменными

### История скидок

Каждый снимок хранит:
- Тип скидки на момент создания
- Процент скидки
- Стоимость до и после скидки

Это позволяет:
- Отслеживать историю изменений скидок
- Анализировать эффективность скидочной программы
- Формировать отчеты

## Примеры использования

### Пример 1: Партнер с растущим бизнесом

**Начало месяца:** 950 объектов → скидка 0%
```
Стоимость в день = 70/30 × 950 = 2216.67 ₽
```

**Середина месяца:** 1100 объектов → скидка 10%
```
Стоимость до скидки = 70/30 × 1100 = 2566.67 ₽
Скидка = 2566.67 × 0.10 = 256.67 ₽
Итого = 2310.00 ₽
```

**Конец месяца:** 2050 объектов → скидка 20%
```
Стоимость до скидки = 70/30 × 2050 = 4783.33 ₽
Скидка = 4783.33 × 0.20 = 956.67 ₽
Итого = 3826.66 ₽
```

### Пример 2: VIP-партнер с индивидуальной скидкой

Для крупного партнера устанавливается ручная скидка 25%:

```json
{
  "discount_type": "manual",
  "manual_discount_percent": 25
}
```

Результат: независимо от количества объектов всегда применяется 25% скидка.

## Преимущества системы

1. **Гибкость:**
   - Автоматические скидки для стандартных условий
   - Ручные скидки для индивидуальных договоренностей

2. **Прозрачность:**
   - Все расчеты видны в UI
   - История сохраняется в снимках

3. **Мотивация роста:**
   - Чем больше объектов, тем выше скидка
   - Стимулирует партнеров увеличивать базу

4. **Простота управления:**
   - Автоматический расчет без вмешательства
   - Легко переключаться между режимами
