# Новые функции подписок

## Реализованные функции

### 1. Старт в будущем (Scheduled Subscriptions)
Подписки могут создаваться со статусом `scheduled`, если дата/время начала в будущем. 

**Новые возможности:**
- **Выбор даты и времени начала**: Вы можете указать не только дату, но и точное время (HH:MM) начала подписки
- **Запуск немедленно**: Опция "Запустить подписку немедленно" позволяет активировать подписку сразу после создания
- **Автоматическая активация**: Если дата/время начала в будущем, подписка автоматически активируется в указанное время

**Автоматическая активация:**

Автоматическая активация происходит не только в 00:00, но в любое указанное время. Рекомендуется запускать проверку каждые 5-15 минут:

```bash
# Добавить в crontab пользователя axenta
*/15 * * * * curl -X POST http://localhost:8080/api/auth/billing/activate-scheduled -H "Authorization: Token YOUR_TOKEN"
```

**Примеры использования:**

1. **Запуск немедленно**: Включите чекбокс "Запустить подписку немедленно" - подписка активируется сразу
2. **Запуск в определенную дату и время**: Укажите дату (например, 25.11.2025) и время (например, 14:30) - подписка активируется в 14:30 25 ноября
3. **Запуск сегодня, но позже**: Если сейчас 18 число, 10:00, вы можете указать 18 число и время 15:00 - подписка активируется в 15:00 сегодня

**Техническая реализация:**
- В API добавлено поле `start_time` (формат HH:MM)
- Логика определения статуса учитывает не только дату, но и время
- Сравнение происходит с текущим моментом (не только с началом дня)

### 2. Смена тарифа в середине месяца
При создании подписки, если дата начала не с начала месяца, мастер предлагает "разбить период" и показывает пропорциональную стоимость в превью.

### 3. Объект уже в подписке
При выборе договора мастер проверяет наличие активных подписок и показывает предупреждение с опцией "перенести в новый тариф".

### 4. Проверка прав на тарифы по договору
Если у договора нет прав на тарифы (tariff_plan_id = 0), шаг 2 блокируется с подсказкой "нет прав на тарифы в этом договоре".

### 5. НДС/ЕСФ-тоггл
В превью подписки доступны переключатели:
- **Показать с НДС** - пересчитывает итоговую цену с учетом НДС
- **ЭСФ требуется** - показывает иконку статуса ЭСФ (определяется по стране покупателя из договора)

## API Endpoints

### Создание подписки
```
POST /api/auth/billing/subscriptions
```

**Тело запроса:**
```json
{
  "company_id": 1,
  "billing_plan_id": 5,
  "start_date": "2024-02-15",
  "start_time": "14:30",
  "contract_id": 10,
  "split_period": true,
  "transfer_from_subscription_id": 3,
  "is_auto_renew": true
}
```

**Параметры:**
- `start_date` (string, optional): Дата начала подписки в формате YYYY-MM-DD
- `start_time` (string, optional): Время начала подписки в формате HH:MM (по умолчанию 00:00)
- `status` (string, optional): Если не указан, определяется автоматически:
  - `scheduled` - если `start_date` + `start_time` в будущем
  - `active` - если `start_date` + `start_time` в прошлом или сейчас

### Активация запланированных подписок
```
POST /api/auth/billing/activate-scheduled
```

Активирует все подписки со статусом `scheduled`, у которых дата/время начала уже наступило (start_date <= текущее время).

## Статусы подписок

- `active` - активная подписка
- `scheduled` - запланированная подписка (будет активирована в дату начала)
- `expired` - истекшая подписка
- `cancelled` - отмененная подписка
- `suspended` - приостановленная подписка
