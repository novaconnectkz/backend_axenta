# Решение проблемы "Роль не назначена" для пользователей Axenta

## 🔍 Проблема

В интерфейсе управления пользователями в колонке "Роль" у всех пользователей отображается "Не назначена", хотя пользователи загружаются из Axenta Cloud API.

### Причина проблемы

1. **Прокси API**: Функция `GetUsersFromAxentaCloud` просто проксирует запросы к Axenta Cloud API
2. **Нет синхронизации**: Пользователи из Axenta не сохраняются в локальной базе данных
3. **Нет ролей**: Пользователям не назначаются роли в CRM системе на основе их типа в Axenta

## ✅ Решение

Реализована полная система синхронизации пользователей с автоматическим назначением ролей.

### 1. **Расширенная модель User**

```go
type User struct {
    // ... существующие поля ...
    
    // Поля для Axenta интеграции
    AxentaUserType string `json:"axenta_user_type"` // partner, client, local
    AxentaUserID   string `json:"axenta_user_id"`   // ID пользователя в Axenta
    IsAxentaUser   bool   `json:"is_axenta_user"`   // Пользователь из Axenta или локальный
    
    // Роль автоматически назначается на основе AxentaUserType
    RoleID uint  `json:"role_id"`
    Role   *Role `json:"role,omitempty"`
}
```

### 2. **AxentaUserService с автоматическим назначением ролей**

```go
func (s *AxentaUserService) SyncUserFromAxentaData(axentaUser *AxentaUserResponse) (*models.User, error) {
    // 1. Ищем или создаем пользователя
    // 2. Обновляем данные из Axenta
    // 3. Автоматически назначаем роль на основе AccountType
    // 4. Сохраняем в локальной базе данных
}
```

### 3. **Автоматическое назначение ролей**

| Тип в Axenta | Роль в CRM | Описание |
|--------------|------------|----------|
| `partner` | `partner` | Партнер с расширенными правами |
| `client` | `client` | Клиент с ограниченными правами |
| `local` | `user` | Локальный пользователь системы |

### 4. **Новые API endpoints**

```bash
# Синхронизация всех пользователей из Axenta
POST /api/auth/axenta-users/sync-all

# Получение синхронизированных пользователей (с ролями)
GET /api/auth/users/synced

# Управление отдельными пользователями
GET /api/auth/axenta-users?type=partner|client|local|all
POST /api/auth/axenta-users/local
PUT /api/auth/axenta-users/:id/role
POST /api/auth/axenta-users/sync
```

### 5. **Frontend интерфейс**

- **Кнопка "Роли Axenta"** в заголовке страницы пользователей
- **Кнопка "Синхронизировать всех"** для массовой синхронизации
- **Статистика по типам** пользователей с ролями
- **Фильтрация** по источнику (Axenta/локальные) и типу

### Процесс синхронизации:

5. **Назначение ролей**: Автоматическое назначение на основе типа

### Маппинг ролей:
```go
func (s *AxentaUserService) mapAccountTypeToUserType(accountType string) string {
    switch accountType {
    case "partner":
        return "partner"  // Роль "Партнер"
    case "client":
        return "client"   // Роль "Клиент"
    default:
        return "client"   // По умолчанию клиент
    }
}
```
