# Автоматический расчет биллинга

## Как это работает

После **первой успешной синхронизации данных** из Axenta Cloud автоматически запускается расчет биллинга за весь период для всех партнеров всех компаний.

### Что происходит автоматически:

1. ✅ **Синхронизация данных** - загрузка аккаунтов и объектов из Axenta Cloud
2. ✅ **Проверка наличия снимков** - система проверяет, есть ли уже созданные снимки
3. ✅ **Автоматический расчет** - если снимков нет, запускается расчет за весь период:
   - Период: **2024-03-14** (начало данных) до **вчерашнего дня**
   - Для всех активных партнерских договоров
   - Для всех компаний (тенантов)

### Когда запускается:

- После успешной синхронизации через `SyncAllAdmins()` (синхронизация всех компаний)
- После успешной синхронизации через `SyncAdmin()` (синхронизация одного администратора)
- **Только один раз** - если снимки уже есть, расчет не запускается

### Логирование:

В логах вы увидите:
```
🤖 Автоматический расчет биллинга: проверка необходимости расчета...
🚀 Автоматический расчет биллинга: снимков нет, запускаем расчет за весь период...
📅 Период расчета: 2024-03-14 - 2025-12-06
📊 Компания 6: найдено 45 активных партнерских договоров
✅ Автоматический расчет биллинга завершен: создано 12345 снимков, ошибок: 0
```

### Задача в БД:

Создается запись в таблице `snapshot_jobs`:
- `job_type = 'manual'`
- `triggered_by = 'auto_after_sync'`
- `status = 'completed'` или `'partial'` (если были ошибки)

### Отключение автоматического расчета:

Если нужно отключить автоматический расчет, закомментируйте вызовы `AutoCalculateBillingForAllPartners()` в файле `services/axenta_sync_service.go`:

```go
// После успешной синхронизации хотя бы одной компании запускаем автоматический расчет биллинга
if successCount > 0 {
    log.Printf("AxentaSync: синхронизация завершена для %d компаний, запускаем автоматический расчет биллинга...", successCount)
    // AutoCalculateBillingForAllPartners() // Отключено
}
```

### Ручной запуск:

Если нужно запустить расчет вручную (например, если автоматический расчет не сработал):

```bash
POST /api/auth/snapshot-jobs/trigger
{
  "mode": "partner_all",
  "date_from": "2024-03-14",
  "date_to": "2025-12-06"
}
```

### Проверка результата:

1. Проверьте таблицу `snapshot_jobs`:
```sql
SELECT * FROM snapshot_jobs 
WHERE triggered_by = 'auto_after_sync' 
ORDER BY created_at DESC 
LIMIT 1;
```

2. Проверьте количество созданных снимков:
```sql
SELECT COUNT(*) FROM partner_daily_snapshots;
```

3. Проверьте через UI на странице "История автоматических снимков"
