# Настройка каналов отправки счетов клиентам

## Обзор

Система поддерживает отправку счетов клиентам через несколько каналов:
- **Email** - отправка на электронную почту
- **Telegram** - отправка через Telegram Bot
- **MAX** - отправка через российский мессенджер MAX

Можно выбрать один или несколько каналов одновременно для отправки счета.

## Как использовать

### 1. Отправка счета через интерфейс

1. Откройте раздел **Биллинг** → **Счета**
2. Найдите счет в статусе "Черновик" (draft)
3. Нажмите кнопку **Отправить** (иконка отправки)
4. В открывшемся диалоге выберите каналы отправки:
   - ✅ **Email** - укажите email адрес клиента (автоматически подтягивается из договора)
   - ✅ **Telegram** - укажите Telegram ID или username (например: @username или 123456789)
   - ✅ **MAX** - укажите MAX ID пользователя
5. Нажмите **Отправить**

### 2. Автоматическое заполнение контактов

Система автоматически подставляет контактную информацию:
- **Email** - из поля `client_email` договора
- **Telegram** и **MAX** - из предыдущих отправок счета (если были)

### 3. Отправка на все каналы сразу

Чтобы отправить счет сразу по всем каналам:
1. Выберите все чекбоксы (Email, Telegram, MAX)
2. Заполните контактную информацию для каждого канала
3. Нажмите **Отправить**

Счет будет отправлен через все выбранные каналы. Если один из каналов не сработает, система продолжит отправку через остальные.

## Настройка интеграций

### Email (SMTP)

Настройка Email отправки:
1. Перейдите в **Настройки** → **Интеграции** → **Email SMTP**
2. Укажите:
   - SMTP сервер (например: smtp.gmail.com)
   - Порт (587 для TLS, 465 для SSL)
   - Имя пользователя и пароль
   - Email отправителя
3. Нажмите **Тестировать подключение**
4. Сохраните настройки

Подробнее: [EMAIL_INTEGRATION.md](./EMAIL_INTEGRATION.md)

### Telegram

Настройка Telegram бота:
1. Создайте бота через [@BotFather](https://t.me/botfather)
2. Скопируйте токен бота
3. Перейдите в **Настройки** → **Интеграции** → **Telegram**
4. Укажите токен бота
5. Сохраните настройки

Подробнее: [TELEGRAM_INTEGRATION.md](./TELEGRAM_INTEGRATION.md)

### MAX Messenger

Настройка MAX бота:
1. Создайте бота через [@MasterBot](https://max.ru) в MAX мессенджере
2. Скопируйте токен бота
3. Перейдите в **Настройки** → **Интеграции** → **MAX**
4. Укажите токен бота
5. Сохраните настройки

Подробнее: [MAX_INTEGRATION.md](./MAX_INTEGRATION.md)

## API

### Отправка счета через API

**Endpoint:** `POST /api/auth/billing/invoices/{id}/send`

**Тело запроса:**
```json
{
  "channels": ["email", "telegram", "max"],
  "contact_info": {
    "email": "client@example.com",
    "telegram": "@client_username",
    "max": "123456789"
  }
}
```

**Параметры:**
- `channels` (array, required) - список каналов для отправки: `email`, `telegram`, `max`
- `contact_info` (object, required) - контактная информация для каждого канала

**Ответ (успех):**
```json
{
  "status": "success",
  "message": "Счет успешно отправлен",
  "data": {
    "id": 123,
    "number": "INV-2025-11-0001",
    "status": "sent",
    "last_sent_at": "2025-11-21T10:30:00Z",
    "last_sent_channels": "email,telegram,max",
    ...
  },
  "sent_channels": "email,telegram,max"
}
```

**Ответ (частичный успех):**
```json
{
  "status": "partial_success",
  "message": "Счет отправлен частично: telegram: ошибка отправки",
  "data": {...},
  "sent_channels": "email,max"
}
```

**Ответ (ошибка):**
```json
{
  "status": "error",
  "error": "Не указан ни один канал отправки"
}
```

## Формат сообщений

### Email

Счет отправляется в виде HTML письма с:
- Номером счета
- Датой выставления
- Сроком оплаты
- Периодом биллинга
- Суммой к оплате
- Описанием

### Telegram / MAX

Счет отправляется в виде текстового сообщения с форматированием HTML:

```
📧 Новый счет на оплату

📄 Номер: INV-2025-11-0001
📅 Дата: 21.11.2025
⏰ Срок оплаты: 05.12.2025
📆 Период: 01.11.2025 - 30.11.2025

💰 Сумма: 5000.00 RUB

Описание счета

Пожалуйста, оплатите счет до указанной даты.
```

## Хранение информации об отправке

После отправки счета в базе данных сохраняется:
- `send_channels` - список каналов, через которые планировалась отправка
- `send_to_email` - email, на который отправлен счет
- `send_to_telegram` - Telegram ID получателя
- `send_to_max` - MAX ID получателя
- `last_sent_at` - дата и время последней отправки
- `last_sent_channels` - каналы, через которые счет был успешно отправлен

## Troubleshooting

### Email не отправляется

1. Проверьте настройки SMTP в **Настройки** → **Интеграции** → **Email SMTP**
2. Убедитесь, что указан правильный email получателя
3. Проверьте логи сервера на наличие ошибок
4. Используйте **Тестировать подключение** для проверки

### Telegram не отправляется

1. Проверьте, что токен бота правильный
2. Убедитесь, что пользователь начал диалог с ботом (отправил /start)
3. Проверьте формат Telegram ID (должен быть числом или @username)
4. Проверьте логи сервера

### MAX не отправляется

1. Проверьте, что токен бота правильный
2. Убедитесь, что MAX доступен (работает только в России)
3. Проверьте формат MAX ID
4. Проверьте логи сервера

### Частичная отправка

Если счет отправлен только через некоторые каналы:
1. Проверьте статус отправки в поле `last_sent_channels`
2. Проверьте логи сервера для деталей ошибки
3. Можно повторить отправку через проблемные каналы
