# Интеграция MAX Messenger

## Обзор

MAX - российский мессенджер с поддержкой ботов через API. Интеграция позволяет отправлять уведомления пользователям через MAX наряду с другими каналами (Email, Telegram, SMS).

## Базовая информация

- **API Endpoint**: `https://botapi.max.ru/`
- **Документация**: См. файл MAX API в документации проекта
- **Регистрация бота**: Через `@MasterBot` в MAX

## Настройки в системе

### Модели данных (Backend)

#### NotificationSettings
```go
// MAX настройки (российский мессенджер)
MaxBotToken    string `json:"max_bot_token"`    // Токен бота MAX
MaxWebhookURL  string `json:"max_webhook_url"`  // URL для вебхуков
MaxEnabled     bool   `json:"max_enabled"`      // Включен ли MAX
MaxUsePolling  bool   `json:"max_use_polling"`  // Long Polling вместо Webhook
MaxParseMode   string `json:"max_parse_mode"`   // HTML/Markdown
```

#### User
```go
MaxID string `json:"max_id"` // ID пользователя в MAX мессенджере
```

#### UserNotificationPreferences
```go
MaxEnabled bool `json:"max_enabled"` // Включить уведомления в MAX
```

### Приоритеты каналов для биллинга

Обновленная схема приоритетов:

```
1. Email       (основной канал)
2. MAX         (новый приоритетный канал для РФ)
3. Telegram    (резервный)
4. SMS         (запасной)
```

## Настройка через интерфейс

### Путь к настройкам

```
Настройки → Уведомления → Каналы уведомлений
```

### Параметры конфигурации MAX

1. **Токен бота MAX** - получить от @MasterBot
2. **Режим парсинга** - HTML или Markdown
3. **Тип получения событий**:
   - Webhook (для продакшена)
   - Long Polling (для разработки/тестирования)
4. **Webhook URL** - если используется Webhook

### Тестирование

В разделе **Биллинг → Настройки → Уведомления** доступна кнопка "Отправить тест" для проверки отправки уведомлений через MAX.

## Создание бота MAX

1. Найдите `@MasterBot` в MAX
2. Отправьте команду `/newbot`
3. Следуйте инструкциям:
   - Введите имя бота
   - Введите username бота (должен заканчиваться на `bot`)
4. Скопируйте полученный токен
5. Вставьте токен в настройки системы

## Методы API MAX

### Основные endpoints:

- `POST /sendMessage` - отправка сообщения
- `POST /setWebhook` - установка webhook
- `GET /getUpdates` - получение обновлений (Long Polling)
- `POST /deleteWebhook` - удаление webhook

### Формат сообщений

MAX поддерживает форматирование:
- **HTML**: `<b>жирный</b>`, `<i>курсив</i>`, `<code>код</code>`
- **Markdown**: `**жирный**`, `*курсив*`, `` `код` ``

## Ограничения

- ⚠️ API доступен только на территории России
- Максимальная длина сообщения: 4096 символов
- Частота запросов: стандартные лимиты для ботов

## Примеры использования

### Отправка счета клиенту

При нажатии "Отправить счёт" в биллинге:
1. Проверяется наличие `MaxID` у пользователя
2. Если MAX включен - отправляется уведомление
3. При ошибке - переключение на следующий канал (Telegram)

### Шаблон сообщения для счёта

```html
<b>📧 Новый счёт #{invoice_number}</b>

💰 Сумма: {amount} руб.
📅 Срок оплаты: {due_date}
🏢 Клиент: {client_name}

Пожалуйста, оплатите счёт до указанной даты.
```

## Миграция БД

При первом запуске после обновления будут добавлены новые поля:
- `notification_settings.max_*` - настройки MAX
- `users.max_id` - ID пользователя в MAX
- `user_notification_preferences.max_enabled` - предпочтения

Миграции применяются автоматически через GORM AutoMigrate.

## Разработка

### Тестирование локально

1. Создайте тестового бота в MAX
2. Включите Long Polling в настройках
3. Используйте тестовый диалог в биллинге

### Webhook для продакшена

1. Настройте HTTPS endpoint: `https://yourdomain.com/api/max/webhook`
2. Укажите URL в настройках MAX
3. MAX будет отправлять обновления на этот URL

## Поддержка

При возникновении проблем:
1. Проверьте валидность токена бота
2. Убедитесь, что сервер доступен из России (для Webhook)
3. Проверьте логи в системе
4. Используйте тестовую отправку для диагностики
