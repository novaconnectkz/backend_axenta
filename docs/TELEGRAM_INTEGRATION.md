# Инструкция по настройке интеграции Telegram Bot

## Описание

Интеграция с Telegram Bot позволяет отправлять уведомления пользователям через Telegram. Вы можете настроить бота для отправки автоматических уведомлений о событиях в системе Axenta CRM.

## Шаг 1: Создание бота в Telegram

1. Откройте Telegram и найдите бота [@BotFather](https://t.me/botfather)
2. Отправьте команду `/newbot` или нажмите кнопку "New Bot"
3. Введите имя для вашего бота (например: "Axenta CRM Notifications")
4. Введите username для бота (должен заканчиваться на `bot`, например: `axenta_crm_bot`)
5. BotFather предоставит вам **токен бота** (выглядит как: `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`)

**Важно:** Сохраните токен в безопасном месте. Он понадобится для настройки интеграции.

## Шаг 2: Получение Chat ID

Chat ID необходим для отправки сообщений в конкретный чат или канал. Есть несколько способов получить Chat ID:

### Способ 1: Для личных чатов

1. Найдите бота [@userinfobot](https://t.me/userinfobot) в Telegram
2. Отправьте ему любое сообщение
3. Бот вернет ваш Chat ID (число, например: `123456789`)

### Способ 2: Для групп и каналов

1. Добавьте бота [@getidsbot](https://t.me/getidsbot) в группу или канал
2. Бот автоматически покажет Chat ID группы/канала
3. Для каналов Chat ID будет отрицательным числом (например: `-1001234567890`)

### Способ 3: Через API (для каналов)

1. Создайте публичный канал
2. Добавьте вашего бота как администратора канала
3. Отправьте сообщение в канал
4. Используйте API: `https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates`
5. Найдите `chat.id` в ответе

**Примечание:** Chat ID можно не указывать, если вы планируете отправлять сообщения разным пользователям программно.

## Шаг 3: Настройка интеграции в Axenta CRM

1. Перейдите в раздел **Настройки** → **Внешние интеграции**
2. Найдите карточку **Telegram Bot**
3. Нажмите кнопку **"Настроить"**
4. Заполните форму:
   - **Bot Token**: Вставьте токен, полученный от BotFather
   - **Chat ID (по умолчанию)**: Введите Chat ID (опционально, если хотите отправлять в один чат по умолчанию)
   - **Режим парсинга**: Выберите формат сообщений:
     - `HTML` - для простого форматирования (рекомендуется)
     - `Markdown` - для форматирования Markdown
     - `MarkdownV2` - для расширенного Markdown
   - **Отключить уведомления**: Включите, если хотите отправлять сообщения без звука
   - **Тихие часы**: Настройте время, когда не отправлять уведомления
     - **Начало**: Время начала тихих часов (например: `22:00`)
     - **Окончание**: Время окончания тихих часов (например: `08:00`)
     - **Включить тихие часы**: Включите переключатель для активации
5. Нажмите **"Сохранить"**

## Шаг 4: Тестирование подключения

1. После сохранения настроек нажмите кнопку **"Тест"** на карточке интеграции
2. Если подключение успешно, вы увидите сообщение "Подключение успешно"
3. Если есть ошибки, проверьте:
   - Правильность токена бота
   - Доступность интернета
   - Что бот не был удален или заблокирован

## Использование интеграции

После настройки интеграция готова к использованию. Система будет автоматически отправлять уведомления через Telegram Bot при наступлении событий:

- Создание и завершение монтажей
- Низкий остаток на складе
- Истекающие договоры
- Просроченные платежи
- Системные ошибки

## Отправка тестового сообщения

Вы можете отправить тестовое сообщение через API:

```bash
POST /api/telegram/send-message
{
  "chat_id": "123456789",
  "text": "Тестовое сообщение",
  "parse_mode": "HTML"
}
```

## Безопасность

- **Никогда не делитесь токеном бота** с третьими лицами
- Токен хранится в зашифрованном виде в базе данных
- Используйте тихие часы, чтобы не беспокоить пользователей в нерабочее время
- Регулярно проверяйте статус интеграции

## Решение проблем

### Ошибка "Неверный токен бота"
- Проверьте, что токен скопирован полностью
- Убедитесь, что бот не был удален
- Создайте нового бота через BotFather, если необходимо

### Сообщения не отправляются
- Проверьте, что Chat ID указан правильно
- Убедитесь, что бот добавлен в группу/канал (если используется)
- Проверьте, что бот не заблокирован пользователем
- Проверьте настройки тихих часов

### Ошибка "Chat not found"
- Убедитесь, что пользователь начал диалог с ботом (для личных чатов)
- Проверьте, что бот добавлен в группу/канал
- Для каналов убедитесь, что бот является администратором
