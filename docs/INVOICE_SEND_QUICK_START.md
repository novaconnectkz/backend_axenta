# Отправка счетов клиентам - Краткая инструкция

## Быстрый старт

### 1. Настройка каналов (один раз)

Перед первым использованием настройте каналы отправки:

#### Email
- Перейдите: **Настройки** → **Интеграции** → **Email SMTP**
- Укажите данные SMTP сервера
- Протестируйте и сохраните

#### Telegram (опционально)
- Создайте бота через @BotFather
- Перейдите: **Настройки** → **Интеграции** → **Telegram**
- Укажите токен бота
- Сохраните

#### MAX (опционально)
- Создайте бота через @MasterBot в MAX
- Перейдите: **Настройки** → **Интеграции** → **MAX**
- Укажите токен бота
- Сохраните

### 2. Отправка счета

1. Откройте **Биллинг** → **Счета**
2. Найдите нужный счет (должен быть в статусе "Черновик")
3. Нажмите кнопку **📤 Отправить**
4. В диалоге выберите каналы:
   - ✅ Email (автоматически заполняется из договора)
   - ✅ Telegram (укажите @username или ID)
   - ✅ MAX (укажите MAX ID)
5. Нажмите **Отправить**

### 3. Отправка на все каналы сразу

Просто выберите все чекбоксы (Email, Telegram, MAX) и заполните контактные данные для каждого канала.

## Что происходит при отправке?

- Счет меняет статус с "Черновик" на "Отправлен"
- Клиент получает уведомление с деталями счета
- Информация об отправке сохраняется в системе
- Если один канал не сработал, остальные все равно отправляются

## Формат уведомления

Клиент получает сообщение с:
- Номером счета
- Датой и сроком оплаты
- Суммой к оплате
- Описанием
