## 🔑 КАК ПОЛУЧИТЬ НАСТОЯЩИЙ ТОКЕН

### Вариант 1: Через интерфейс Axenta CRM (ваша система)

1. Войдите в систему как пользователь
2. Перейдите в **Настройки** (`/settings`)
3. Откройте **Axenta Cloud API**
4. В разделе **"Токен авторизации"** будет показан ваш действующий токен
5. Скопируйте токен

### Вариант 2: Через API Axenta Cloud напрямую

```bash
# Авторизация
curl -X POST https://axenta.cloud/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{
    "username": "ваш_email@example.com",
    "password": "ваш_пароль"
  }'

# Ответ содержит токен:
{
  "token": "ваш_настоящий_токен_здесь",
  "user": { ... }
}
```

### Вариант 3: Создать новый токен через интерфейс Axenta Cloud

1. Перейдите на https://axenta.cloud
2. Войдите в систему
3. Настройки → API → Создать токен
4. Скопируйте созданный токен

## 🚀 КАК НАСТРОИТЬ СИСТЕМУ

### Способ 1: Через настройки интерфейса (РЕКОМЕНДУЕТСЯ)

1. **Войдите в CRM** как администратор
2. **Перейдите в Настройки** → Интеграции → Axenta Cloud API
3. **Заполните форму:**
   - API URL: `https://axenta.cloud`
   - Username: `ваш_email@example.com`
   - Password: `ваш_пароль`
4. **Нажмите "Сохранить"**
5. Система автоматически получит и сохранит токен

### Способ 2: Установка токена вручную в БД

```sql
-- Добавьте токен в таблицу user_tokens
INSERT INTO tenant_186.user_tokens 
  (user_id, username, token, account_id, is_active, expires_at, created_at, updated_at)
VALUES 
  (1, 'admin@example.com', 'ВАШ_НАСТОЯЩИЙ_ТОКЕН_ЗДЕСЬ', 186, true, 
   NOW() + INTERVAL '365 days', NOW(), NOW());
```

### Способ 3: Через переменную окружения

```bash
# Установите переменную окружения
export AXENTA_ADMIN_TOKEN='ВАШ_НАСТОЯЩИЙ_ТОКЕН_ЗДЕСЬ'

# Перезапустите backend
cd /Users/com/backend_axenta
./backend_axenta
```
