# Исправление отображения меню выбора для ИП

## Проблема
При вводе ИНН ИП в карточке создания договора система не показывала выпадающий список с найденным ИП для выбора. Вместо этого данные автоматически заполнялись или система "перебрасывала" в карточку ИП без возможности выбора.

## Причина
1. Меню с предложениями было только для организаций, но не для ИП
2. Поле ИНН для ИП не имело привязанного меню с результатами поиска
3. Не было подсказки о том, что нужно выбрать ИП из списка

## Внесенные исправления

### 1. Добавлено меню выбора для ИП
**Файл:** `/Users/com/frontend_axenta/src/views/CreateContract.vue`

**Добавлено:**
- Выпадающее меню с результатами поиска для ИП (аналогично организациям)
- Отдельный ref `innAutocompleteRefIP` для правильной привязки меню к полю ИНН ИП
- Иконка с подсказкой о том, как работает автозаполнение для ИП

### 2. Улучшена подсказка для ИП
**Добавлено:**
- Подсказка "Введите ИНН (12 цифр) или ОГРНИП (13 цифр) для автозаполнения"
- Информационная иконка с подробным описанием процесса автозаполнения
- Указание, что после ввода появится список для выбора

### 3. Визуальное отличие для ИП
**Добавлено:**
- Иконка `mdi-account-tie` для ИП в списке предложений (вместо `mdi-domain` для организаций)
- Текст "Поиск ИП..." при загрузке данных

## Результат
Теперь при вводе ИНН ИП (например, `342304181660`):
1. ✅ Выполняется поиск через Dadata API
2. ✅ Показывается выпадающий список с найденным ИП
3. ✅ Пользователь может выбрать ИП из списка для автозаполнения
4. ✅ Данные заполняются только после выбора из списка
5. ✅ Показывается подсказка о том, как работает автозаполнение
