# Руководство по настройке скидок для партнерских договоров

## Где выбирать тип скидки?

### При создании нового партнерского договора

1. Откройте **Биллинг → Договоры**
2. Нажмите кнопку **"Создать договор"**
3. Выберите **Тип договора: "Партнерский"**
4. После выбора типа договора появится секция **"Настройка скидок"** (с зеленой рамкой и иконкой скидки)

### Настройки скидок

В секции "Настройка скидок" вы увидите:

#### 1. **Тип скидки** (выпадающий список)

**Три варианта:**

##### ✅ **Без скидки** (по умолчанию)
- Полная стоимость без применения скидок
- Используется стандартный расчет: Тариф × Количество объектов

##### 📝 **Ручная скидка**
- При выборе этого варианта появляется поле **"Процент скидки"**
- Можно указать от 0 до 100%
- Скидка будет применяться независимо от количества объектов
- **Пример использования:** VIP-партнер с индивидуальными условиями

##### 🤖 **Автоматическая скидка**
- Скидка рассчитывается автоматически на основе количества активных объектов:
  - **≥ 1000 объектов** → скидка 10%
  - **≥ 2000 объектов** → скидка 20%
  - **≥ 4000 объектов** → скидка 30%
  - **< 1000 объектов** → без скидки
- При выборе показывается информационное сообщение
- **Пример использования:** стандартные условия для всех партнеров

#### 2. **Процент скидки** (только для ручной скидки)
- Появляется только при выборе "Ручная скидка"
- Числовое поле от 0 до 100
- Можно указывать дробные значения (например, 15.5%)

## Пример настройки

### Вариант 1: Стандартный партнер с автоскидкой

```
Тип договора: Партнерский
Учетная запись партнера: ОБЩЕСТВО С ОГРАНИЧЕННОЙ ОТВЕТСТВЕННОСТЬЮ "ИТАЛОН"
Тарифный план: Базовый - 70 ₽/мес
───────────────────────────────────────────────────
🔖 Настройка скидок
───────────────────────────────────────────────────
Тип скидки: [Автоматическая скидка ▼]

ℹ️ Скидка будет автоматически рассчитываться при создании снимков
   на основе количества активных объектов
```

**Результат:**
- Если у партнера 1152 объекта → скидка 10%
- Стоимость: 2687.96 ₽ → **2419.16 ₽/день**

### Вариант 2: VIP-партнер с фиксированной скидкой

```
Тип договора: Партнерский
Учетная запись партнера: ООО "КРУПНЫЙ ПАРТНЕР"
Тарифный план: Базовый - 70 ₽/мес
───────────────────────────────────────────────────
🔖 Настройка скидок
───────────────────────────────────────────────────
Тип скидки: [Ручная скидка ▼]
Процент скидки: [25] % (0-100%)
```

**Результат:**
- Независимо от количества объектов → скидка 25%
- Всегда применяется фиксированная скидка

### Вариант 3: Без скидки

```
Тип договора: Партнерский
Учетная запись партнера: ООО "НОВЫЙ ПАРТНЕР"
Тарифный план: Базовый - 70 ₽/мес
───────────────────────────────────────────────────
🔖 Настройка скидок
───────────────────────────────────────────────────
Тип скидки: [Без скидки ▼]
```

**Результат:**
- Стандартная стоимость без скидок
- Расчет: Тариф × Объекты = Стоимость

## Как посмотреть применение скидок?

После создания снимков:

1. Откройте **Биллинг → Договоры**
2. Найдите нужный партнерский договор
3. Нажмите на иконку **📊 (калькулятор)** в столбце "Действия"
4. В открывшемся окне в таблице "Ежедневные снимки" вы увидите:

```
ДАТА       | ВСЕГО | АКТИВНЫХ | ТАРИФ   | СКИДКА      | СТОИМОСТЬ ЗА ДЕНЬ
01.11.2025 | 687   | 684      | 70,00 ₽ | -10%        | 1 595,98 ₽
           |       |          |         | 177.33 ₽    | (было 1 773.31 ₽)
```

**Колонка "Скидка":**
- ✅ Если есть скидка: зеленый чип с процентом + сумма экономии
- — Если нет скидки: прочерк

**Колонка "Стоимость за день":**
- Если есть скидка: 
  - ~~Зачеркнутая~~ стоимость до скидки
  - **Зеленая** итоговая стоимость
- Если нет скидки: обычная стоимость

## Изменение скидок для существующего договора

### Через редактирование договора (планируется):
1. Откройте договор
2. Нажмите "Редактировать"
3. Измените тип скидки или процент
4. Сохраните изменения

⚠️ **Важно:** Изменение настроек скидки повлияет только на **новые снимки**. Исторические данные остаются неизменными.

### Пересоздание снимков с новыми скидками:
1. Измените настройки скидки в договоре
2. Откройте статистику договора (📊)
3. Выберите нужный период
4. Нажмите **"Создать снимки"**
5. Снимки будут пересозданы с новыми настройками скидок

## Часто задаваемые вопросы

### Q: Можно ли применить скидки к уже созданным снимкам?
**A:** Да, просто пересоздайте снимки за нужный период. Существующие снимки будут обновлены с новыми настройками скидок.

### Q: Какая скидка лучше - ручная или автоматическая?
**A:** 
- **Автоматическая** - для стандартных условий, мотивирует партнеров увеличивать базу
- **Ручная** - для индивидуальных договоренностей с конкретными партнерами

### Q: Можно ли комбинировать ручную и автоматическую скидки?
**A:** Нет, нужно выбрать один из вариантов. Применяется либо ручная, либо автоматическая скидка.

### Q: Что происходит при изменении количества объектов?
**A:** 
- **Автоматическая скидка:** пересчитывается при каждом новом снимке
- **Ручная скидка:** остается неизменной

### Q: Видно ли сумму экономии от скидки?
**A:** Да, в таблице ежедневных снимков отображается:
- Процент скидки
- Сумма скидки в рублях
- Стоимость до и после скидки

## Технические детали

### Поля в базе данных

**Таблица `contracts`:**
- `discount_type` - тип скидки (none/manual/auto)
- `manual_discount_percent` - процент ручной скидки (0-100)
- `use_auto_discount` - флаг использования автоскидок

**Таблица `partner_daily_snapshots`:**
- `discount_type` - тип скидки на момент снимка
- `discount_percent` - примененный процент
- `cost_before_discount` - стоимость до скидки
- `discount_amount` - сумма скидки
- `daily_cost` - итоговая стоимость

### API

**При создании договора отправляйте:**
```json
{
  "contract_type": "partner",
  "partner_company_id": 2,
  "tariff_plan_id": 1,
  "discount_type": "auto",  // или "manual" или "none"
  "manual_discount_percent": 15.5,  // только для manual
  "use_auto_discount": true  // для auto
}
```
