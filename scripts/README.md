# Скрипты для работы с API Axenta

## Описание

Этот каталог содержит скрипты для тестирования и работы с API Axenta CRM.

## Скрипт авторизации и получения учётных записей

### Файлы
- `axenta_auth_test.ts` - базовый TypeScript скрипт
- `axenta_auth_advanced.ts` - расширенный скрипт с диагностикой и переменными окружения
- `package.json` - зависимости и npm скрипты
- `tsconfig.json` - конфигурация TypeScript
- `env.example` - пример файла с переменными окружения
- `README.md` - данная документация

### Функциональность
Скрипт выполняет следующие действия:
1. 🔐 Авторизация в API Axenta через POST запрос на `/auth/login/`
2. 📋 Получение списка учётных записей через GET запрос на `/cms/accounts/`
3. 📊 Отображение результатов в виде красивой таблицы в консоли
4. 🔍 Диагностика подключения и детальная обработка ошибок

### Установка зависимостей

```bash
# Перейти в папку scripts
cd /Users/com/backend_axenta/scripts

# Установить зависимости
npm install
```

### Использование

#### Быстрый запуск

**Базовый скрипт:**
```bash
npm run test-auth
```

**Расширенный скрипт с диагностикой:**
```bash
npm run test-auth-advanced
```

#### Альтернативные способы запуска
```bash
# Прямой запуск базового скрипта
npx tsx axenta_auth_test.ts

# Прямой запуск расширенного скрипта
npx tsx axenta_auth_advanced.ts

# Режим разработки с автоперезагрузкой
npm run dev                    # базовый скрипт
npm run dev-advanced          # расширенный скрипт

# Компиляция в JavaScript
npm run build
```

### Настройка учетных данных

#### Способ 1: Переменные окружения (рекомендуется)

1. Скопируйте файл с примером:
```bash
cp env.example .env
```

2. Отредактируйте `.env` файл с реальными данными:
```bash
AXENTA_USERNAME=ваш_email@example.com
AXENTA_PASSWORD=ваш_пароль
AXENTA_BASE_URL=https://axenta.cloud/api
DEBUG_MODE=true
```

3. Запустите расширенный скрипт:
```bash
npm run test-auth-advanced
```

#### Способ 2: Прямое редактирование кода

Для базового скрипта отредактируйте переменную `credentials` в файле `axenta_auth_test.ts`:

```typescript
const credentials: LoginCredentials = {
  username: 'ваш_email@example.com',
  password: 'ваш_пароль'
};
```

### Обработка ошибок

Скрипт обрабатывает следующие типы ошибок:
- **401** - Неверные учетные данные
- **403** - Недостаточно прав доступа
- **404** - Endpoint не найден
- **429** - Превышен лимит запросов
- **Network errors** - Проблемы с подключением к серверу

### Переиспользование функций

Функции можно импортировать в других скриптах:

```typescript
import { login, getAccounts, displayAccountsTable } from './axenta_auth_test';

// Использование функций
const authData = await login({ username: 'user', password: 'pass' });
const accounts = await getAccounts(authData.access);
displayAccountsTable(accounts);
```

### Зависимости

- **axios** - HTTP клиент для запросов к API
- **console-table-printer** - красивое отображение таблиц в консоли
- **typescript** - поддержка TypeScript
- **tsx** - выполнение TypeScript файлов без компиляции

### Безопасность

⚠️ **Важно:** Не коммитьте реальные учетные данные в репозиторий!

Для продакшена рекомендуется использовать переменные окружения:

```typescript
const credentials: LoginCredentials = {
  username: process.env.AXENTA_USERNAME || 'user@example.com',
  password: process.env.AXENTA_PASSWORD || 'password123'
};
```
