# 🌐 Веб-интерфейс для просмотра данных API Axenta

## 🚀 Быстрый старт

### 1. Запуск веб-интерфейса
```bash
cd /Users/com/backend_axenta/scripts
npm run start-viewer
```

### 2. Откройте в браузере
```
http://localhost:3001
```

## 📱 Как использовать

### Шаг 1: Введите учетные данные
- **Email пользователя**: ваш логин в Axenta
- **Пароль**: ваш пароль
- **Базовый URL API**: `https://axenta.cloud/api` (уже заполнен)

### Шаг 2: Подключитесь к API
- Нажмите кнопку "🚀 Подключиться к API"
- Дождитесь результата авторизации

### Шаг 3: Просматривайте данные
После успешной авторизации вы увидите:

1. **📋 Результат авторизации** - токены доступа и детали ответа
2. **📋 Результат получения аккаунтов** - полный JSON ответ от API
3. **📊 Таблица аккаунтов** - удобное табличное представление
4. **📈 Статистика** - сводная информация по аккаунтам

## 🎯 Что вы увидите

### Информация об авторизации:
```json
{
  "access": "eyJ0eXAiOiJKV1QiLCJhbGciOiJIUzI1NiJ9...",
  "refresh": "eyJ0eXAiOiJKV1QiLCJhbGciOiJIUzI1NiJ9..."
}
```

### Структура аккаунта:
```json
{
  "id": 123,
  "name": "ООО Рога и Копыта",
  "manager": "Иван Иванов",
  "service_company": "СервисТех",
  "objects_count": 25,
  "status": "active",
  "created_at": "2024-01-15T10:30:00Z",
  "updated_at": "2024-10-10T16:45:00Z"
}
```

### Таблица аккаунтов:
| ID  | Название          | Менеджер     | Сервисная компания | Кол-во объектов | Статус |
|-----|-------------------|--------------|-------------------|-----------------|--------|
| 123 | ООО Рога и Копыта | Иван Иванов  | СервисТех         | 25              | active |

### Статистика:
- **Всего аккаунтов**: количество загруженных записей
- **Активных аккаунтов**: количество активных записей
- **Всего объектов**: сумма всех объектов по всем аккаунтам
- **Среднее на аккаунт**: среднее количество объектов на аккаунт

## 🔧 Возможности интерфейса

### ✅ Что работает:
- **Авторизация в API Axenta** - полная поддержка
- **Получение списка аккаунтов** - с пагинацией
- **Просмотр JSON ответов** - с подсветкой синтаксиса
- **Табличное представление** - удобная таблица
- **Статистика в реальном времени** - автоматический расчет
- **Обработка ошибок** - понятные сообщения об ошибках
- **Адаптивный дизайн** - работает на мобильных устройствах

### 🎨 Особенности интерфейса:
- **Современный дизайн** - красивый градиентный интерфейс
- **Анимации** - плавные переходы и эффекты
- **Цветовая индикация** - зеленый для успеха, красный для ошибок
- **Автоматические уведомления** - исчезают через 5 секунд
- **Полная типизация** - все данные корректно отображаются

## 🛠️ Технические детали

### Файлы:
- `axenta_api_viewer.html` - основной HTML файл с интерфейсом
- `start_viewer.ts` - HTTP сервер для запуска страницы
- `WEB_VIEWER_INSTRUCTIONS.md` - данная инструкция

### Технологии:
- **Vanilla JavaScript** - без внешних зависимостей
- **Fetch API** - для HTTP запросов
- **CSS Grid/Flexbox** - для адаптивной верстки
- **Node.js HTTP Server** - для локального хостинга

### Безопасность:
- **CORS настроен** - для работы с внешними API
- **Токены не сохраняются** - только в памяти браузера
- **Локальный сервер** - данные не передаются третьим лицам

## 🚫 Остановка сервера

Для остановки веб-сервера:
1. Перейдите в терминал где запущен сервер
2. Нажмите `Ctrl+C`

Или найдите процесс и завершите его:
```bash
lsof -ti:3001 | xargs kill
```

## 🔍 Альтернативные способы просмотра данных

Если веб-интерфейс не подходит, используйте:

### Консольные скрипты:
```bash
# Детальный анализ в консоли
DEBUG_MODE=true AXENTA_USERNAME=ваш_email AXENTA_PASSWORD=ваш_пароль npm run test-auth-advanced

# Быстрый тест
npx tsx quick_api_test.ts ваш_email@example.com ваш_пароль

# Исследование API
npm run explore-api
```

## 💡 Советы по использованию

1. **Откройте Developer Tools** (F12) для просмотра сетевых запросов
2. **Используйте разные браузеры** для тестирования совместимости
3. **Проверьте консоль браузера** при возникновении ошибок
4. **Сохраните данные** - скопируйте JSON если нужно
5. **Тестируйте с разными аккаунтами** для полноты картины
