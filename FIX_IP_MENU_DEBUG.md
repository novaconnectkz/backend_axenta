# Исправление отображения меню выбора для ИП - Отладка

## Проблема
При вводе ИНН ИП данные получаются успешно (видно в логах), но меню выбора не показывается пользователю.

## Внесенные исправления для отладки

### 1. Добавлено логирование
**Файл:** `/Users/com/frontend_axenta/src/views/CreateContract.vue`

**Добавлено логирование в функции `searchOrganizations`:**
- Логирование количества предложений
- Логирование первого предложения
- Логирование типа клиента
- Логирование состояния ref'ов
- Логирование состояния меню

### 2. Улучшена обработка blur события
**Изменение в функции `handleInnBlur`:**
```typescript
// Было:
setTimeout(() => {
  showOrganizationMenu.value = false;
}, 200);

// Стало:
setTimeout(() => {
  // Проверяем, не кликнул ли пользователь на элемент меню
  if (!document.activeElement?.closest('.v-menu__content')) {
    showOrganizationMenu.value = false;
  }
}, 300);
```

### 3. Добавлено свойство `:close-on-content-click="false"`
**Добавлено в оба меню (для организаций и ИП):**
- Меню не будет закрываться при клике на содержимое
- Пользователь сможет спокойно выбрать предложение

### 4. Улучшена логика активатора меню
**Изменение:**
- Для организаций: используется `innAutocompleteRef`
- Для ИП: используется `innAutocompleteRefIP`
- Условный выбор активатора в зависимости от типа клиента

### 5. Добавлено логирование в handleInnFocus
**Добавлено:**
- Логирование при фокусе на поле ИНН
- Помогает понять, когда меню должно показываться

## Как проверить

1. Откройте консоль браузера (F12)
2. Выберите тип клиента "Индивидуальный предприниматель"
3. Введите ИНН ИП: `342304181660`
4. Проверьте логи в консоли:
   - Должны появиться логи с префиксом `📋`
   - Проверьте значения `innAutocompleteRefIP`
   - Проверьте значение `showOrganizationMenu`
5. Меню должно появиться под полем ИНН

## Возможные проблемы

1. **Ref не установлен** - если `innAutocompleteRefIP` равен `null`, меню не сможет привязаться к элементу
2. **Меню закрывается сразу** - проверьте, не срабатывает ли `handleInnBlur` слишком быстро
3. **Активатор не работает** - возможно, нужно использовать другой подход для привязки меню

## Следующие шаги

Если меню все еще не показывается:
1. Проверьте логи в консоли
2. Убедитесь, что `innAutocompleteRefIP` не равен `null`
3. Попробуйте использовать один общий ref для обоих случаев
4. Рассмотрите использование `v-autocomplete` вместо `v-menu`
