# Инструкция по тестированию статистики партнерских договоров

## Что было реализовано

✅ Выбор произвольного периода для статистики (date pickers)  
✅ Создание снимков за любой прошедший период  
✅ Учет дат создания объектов  
✅ Учет дат активации и деактивации объектов  

## Как протестировать

### 1. Запустите приложение

**Backend:**
```bash
cd /Users/com/backend_axenta
go run main.go
```

**Frontend:**
```bash
cd /Users/com/frontend_axenta
npm run dev
```

### 2. Откройте статистику партнерского договора

1. Перейдите в раздел "Биллинг" → вкладка "Договоры"
2. Найдите партнерский договор (тип: "Партнерский")
3. Нажмите на иконку калькулятора (📊) в столбце "Действия"

### 3. Выберите период

В открывшемся диалоге вы увидите:
- Поле "Дата начала"
- Поле "Дата окончания"
- Кнопку "Применить"
- Кнопку "Создать снимки"

**По умолчанию:**
- Дата начала = дата начала договора (или 30 дней назад)
- Дата окончания = сегодня

### 4. Создайте снимки за период (если их нет)

1. Выберите нужный период (например, последние 7 дней)
2. Нажмите "Создать снимки"
3. Дождитесь завершения (появится уведомление)
4. Автоматически загрузится статистика

### 5. Просмотрите статистику

Вы увидите:
- **Сводную информацию:**
  - Всего дней
  - Среднее количество объектов
  - Месячный тариф
  - Общая стоимость
  
- **Таблицу ежедневных снимков:**
  - Дата
  - Всего объектов
  - Активных объектов
  - Тариф за месяц
  - Стоимость за день

### 6. Проверьте учет дат создания объектов

Для проверки правильности работы:

1. Создайте снимки за период **до** даты создания некоторых объектов
2. Создайте снимки за период **после** даты создания этих объектов
3. Сравните количество объектов - оно должно отличаться

**Пример:**
- Объект создан 15 ноября 2025
- Снимок на 10 ноября → объект НЕ учитывается
- Снимок на 20 ноября → объект учитывается

## Тестовые сценарии

### Сценарий 1: Просмотр статистики за последнюю неделю

1. Откройте статистику партнерского договора
2. Установите период: последние 7 дней
3. Нажмите "Применить"
4. Если снимков нет, нажмите "Создать снимки"
5. Проверьте, что отображаются все 7 дней

### Сценарий 2: Просмотр статистики за месяц

1. Откройте статистику партнерского договора
2. Установите период: весь ноябрь (01.11.2025 - 30.11.2025)
3. Нажмите "Применить"
4. Если снимков нет, нажмите "Создать снимки" (это займет ~30-60 секунд)
5. Проверьте, что отображаются все 30 дней
6. Проверьте общую стоимость

### Сценарий 3: Обновление существующих снимков

1. Создайте снимки за период (например, последние 7 дней)
2. Нажмите "Создать снимки" повторно для того же периода
3. Проверьте, что данные обновились (время обновления в логах)
4. Убедитесь, что снимки не задублировались

### Сценарий 4: Изменение периода

1. Откройте статистику с периодом по умолчанию
2. Измените период на последние 3 дня
3. Нажмите "Применить"
4. Проверьте, что отображаются только снимки за последние 3 дня
5. Проверьте, что общая стоимость пересчиталась

## Проверка в логах

При создании снимков в логах backend должны появиться:

```
📸 Создание снимков для договора ID=35 за период
✅ Снимок создан: договор=Т-291125/058, дата=2025-11-28, объектов=1186 (активных=1152), цена/день=2.3333₽, стоимость=2687.96₽
```

При загрузке объектов с учетом дат:

```
📄 Страница 1: получено 1186 объектов, всего загружено 1186 из 1186
✅ Объектов партнера 2 на дату 2025-11-28: 1186 (активных: 1152, неактивных: 34)
```

## Что проверить

- ✅ Date pickers работают корректно
- ✅ Кнопка "Применить" загружает данные за выбранный период
- ✅ Кнопка "Создать снимки" создает снимки для всех дней периода
- ✅ При создании снимков показывается индикатор загрузки
- ✅ После создания снимков показывается уведомление с результатом
- ✅ Статистика автоматически обновляется после создания снимков
- ✅ Таблица показывает правильное количество объектов для каждого дня
- ✅ Формула расчета работает корректно (дневная цена × активные объекты)
- ✅ Итоговая сумма корректно суммируется

## Известные ограничения

⚠️ **Важно**: Текущая реализация использует актуальный статус `isActive` из Axenta Cloud API для всех дат. Это означает:

- Если объект был активен в прошлом, но сейчас неактивен → он будет учитываться как неактивный для всех прошлых дат
- Если объект был неактивен в прошлом, но сейчас активен → он будет учитываться как активный для всех прошлых дат

Это ограничение связано с тем, что Axenta Cloud API не предоставляет историю изменений статусов объектов.

**Что учитывается корректно:**
✅ Дата создания объекта (`createdAt`)  
✅ Дата удаления объекта (`deletedAt`)  

## Что делать при проблемах

### Проблема: Снимки не создаются

**Решение:**
1. Проверьте логи backend на наличие ошибок
2. Проверьте, что токен авторизации действителен
3. Проверьте, что договор является партнерским (`contract_type = 'partner'`)
4. Проверьте, что у договора указан `partner_company_id` и `tariff_plan_id`

### Проблема: Неправильное количество объектов

**Решение:**
1. Проверьте логи backend - там показывается количество объектов из Axenta Cloud
2. Сравните с данными напрямую из Axenta Cloud API
3. Проверьте даты создания объектов в Axenta Cloud

### Проблема: Долго создаются снимки

**Ожидаемое поведение:**
- Для периода 7 дней: ~7-15 секунд
- Для периода 30 дней: ~30-60 секунд
- Для периода 90 дней: ~90-180 секунд

Это нормально, так как для каждого дня делается запрос к Axenta Cloud API.
